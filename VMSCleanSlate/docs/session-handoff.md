## Quick start

작업 폴더:

`D:\kjwook2023\vms\vmscleanslate`

현재 핵심 상태:

- 리팩터링 적용 완료
- UTF-8 BOM 파서 이슈 수정 완료
- 새 작업 폴더 기준 빌드/퍼블리시 완료
- `2026-05-07` 수동 테스트는 체감상 정상
- `2026-05-11` 기준 설정 창과 설정 파일 열기 메뉴에 암호 보호 추가
- `2026-05-11` 기준 배포용 publish exe 재생성 완료
- `2026-05-11` 기준 설정 화면에 항목별 정보 아이콘/툴팁 추가
- `2026-05-14` 기준 `dotnet build -c Release` 재확인 완료
- `2026-05-14` 기준 설정 암호는 외부 `pw.env` 없이 고정 해시 비교로 동작
- 현재 작업 폴더에는 `logs` 디렉터리가 없어 최신 런타임 로그는 아직 없음
- 다만 현재 셸 기준 자동 시작과 GPO 훅은 활성화 확인되지 않음

다음 우선순위:

1. `docs\session-handoff-2026-05-14.md` 기준으로 대상 PC 실기 검증 시작
2. 대상 PC의 실제 사용자 계정에서 자동 시작 등록 상태 재확인
3. 재부팅 후 트레이 자동 실행 여부 확인
4. 최신 publish exe 로 설정 암호 팝업과 설정 툴팁 UI 확인
5. 로그오프/종료 경로 각각 재시험
6. 새 로그에서 parser error 재발 여부 확인
7. 암호 변경이 필요하면 `SettingsPassword.cs` 고정 해시 갱신 후 재빌드
